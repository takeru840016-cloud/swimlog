# Security Policy

## Supported versions

Security fixes are provided for the latest version on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or for an exposed secret.

Use GitHub's private vulnerability reporting feature when it is enabled for the repository. If it is not available, contact the repository maintainer privately through the contact method listed on their GitHub profile. Include the affected endpoint or file, reproduction steps, and potential impact. Do not include PINs, secret values, session cookies, or personal athlete data.

The maintainer will acknowledge the report, investigate it privately, and coordinate a fix before public disclosure.
